# MOSS 漫画参考图反推：通用版

将漫画参考图拆成可编辑分格、跨格人物、字区和框用途，输出配套 MOSS 漫画节点使用的版式与内容 JSON。支持按要求替换角色、导入版式库及使用自己的工作流实际测试。

## 规则与流程的关系

`SKILL.md` 是执行入口；反推图或修订版式前要求完整读取随包的 `references/layout-rules.md`。核心规则只维护这一份，包含分格、斜框、局部定位、跨格、多尺度展示和交付检查。节点接口与采样环境按任务再读对应资料。

仓库 `docs/` 中的可复制 TXT 由核心规则生成，适合不安装 skill 的普通看图 LLM。只安装完整 skill 文件夹即可使用，不依赖仓库外的 docs。色彩、尺寸等缺省值遵循核心规则，用户明确要求始终优先。

## 在其他 agent 中使用

- **支持 SKILL.md 的 agent**：按该 agent 的技能安装方式放入整个 `moss-comic-reference-layout` 文件夹，不能只复制主文件。重新发现或加载技能后调用；安装目录以该 agent 为准。
- **不支持技能自动加载的 agent**：提供整个解压目录，使用下方指令要求读取主文件及按需引用的资料。这是手动加载流程，不代表 agent 会自动发现技能。
- **Codex**：可将文件夹放入当前使用者的技能目录（通常为 `~/.codex/skills`），通过 `$moss-comic-reference-layout` 调用。已有同名个人版时先备份并选择使用哪一版，避免直接覆盖。

```text
请读取我提供的 moss-comic-reference-layout/SKILL.md，按其中流程分析这张漫画参考图。
保留参考图的分格、跨格主体及阅读关系，将人物替换为【角色】。
成图采用【彩色/黑白】，对白为【语言】，拟声为【语言和字体】。
输出可编辑 layout.json、框用途和 prompt.json。
需要编译或试跑时使用我提供的环境信息，不要假定原作者的路径或端口。
```

要求试跑时再提供：节点目录、ComfyUI URL、可用 MOSS 工作流、Python 与输出目录。模型需要在自己的环境可用。技能本身不提供模型、图片生成 API 或云端额度。

## 依赖和可用范围

- 分析漫画和检查成图需要 agent 能查看图片；只有文本能力时不能宣称完成视觉检查。
- 版式编译、库导入与可视化编辑依赖配套 `ComfyUI-MOSS-MangaLayout` 节点；需另外安装。尚未安装时可以先生成未编译草稿。
- 实际生成需要可用 MOSS 工作流，以及 agent 的文件、Python、HTTP 等运行工具。受限环境可交付文件供手动执行。
- 没有固定本机路径、端口、工作流编号或人物默认值。案例的角色、语言、尺寸和字体仅为示例，新任务遵循使用者要求。

`scripts/compile_template.py --help` 提供命令参数。`agents/openai.yaml` 是可选的 Codex 界面元数据，其他 agent 可以忽略。

## 随包案例及验证范围

包含阿罗娜、飞鸟马时两套 JSON，演示跨格主体和框用途。未携带原漫画图片、账号配置、凭证或模型。

通用版在制作环境进行了两套案例编译和数据检查；案例曾使用配套节点实际生成。尚未在其他电脑或其他 agent 中实测，生成速度和画面还原度取决于各自环境。
