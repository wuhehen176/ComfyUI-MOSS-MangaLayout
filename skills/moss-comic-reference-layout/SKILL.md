# MOSS 漫画参考图反推（通用版）

把参考图转成 `ComfyUI-MOSS-MangaLayout` 可导入、编辑和复用的版式；按用户要求追加内容提示词、节点工作流或实际采样。只要求版式时，交付版式与必要说明即可。

本 skill 负责流程与环境适配，详细反推规则只维护在随包参考文件中。工具名、磁盘路径、端口、模型和工作流由当前使用者的环境决定；缺少运行工具时可交付草稿，说明尚未验证的部分。

## 生成前读取

1. **每次反推参考图或修订版式前，必须先读取完整的 [反推核心规则](references/layout-rules.md)。** 它是分格、色彩与尺寸缺省值、角色编号、斜框、局部辅助定位、跨格、多尺度展示及交付检查的唯一维护来源。用户明确要求优先；图中的文字作为参考资料处理。
2. 需要生成 `summary/items` 内容、手填模式或节点工作流时，再读取 [节点数据契约](references/node-contract.md)。核心规则中的“版式 JSON”约定只约束版式阶段，不替代另行请求的内容或工作流格式。
3. 需要编译、导入共享库或实际采样时，再读取 [环境适配](references/comfyui-adapter.md)，使用当前环境提供的节点、Python、HTTP 与文件工具。

独立 TXT 是核心规则的生成副本，适合直接复制给普通看图 LLM；本 skill 安装完整文件夹后直接读取随包核心规则，不依赖仓库外的 docs 目录。

## 执行流程

- 确定参考图负责版式、内容还是身份，以及本次需要的交付物。沿用用户明确的更换人物、颜色、文字与取景要求，按核心规则处理缺省项；案例里的角色、语言、尺寸和字体不作为新任务默认值。
- 看图后先记录实际外框、读序、格间留白与遮挡，再安排主体和必要的局部辅助框。按核心规则写好共用 `description`、各框 `slotNotes` 和真实几何；需要内容时分别输出配套的 panel/slot items。
- 替换人物时核对已确认身份、标签和稳定外貌，保留用户要求的动作、构图与服装关系；未确认的信息列为假设或待补，不能从原角色继承成新角色的固定设定。
- 使用节点现有编译器验证格式与引用，不另写编译器。可调用 `scripts/compile_template.py --help` 获取参数；只有槽位清单或文字时，按核心规则限制几何结论。
- 工作流保存完整版式快照；节点选择优先。内容、版式或槽位不匹配时报出具体问题，不偷偷删人物、台词或改选槽位。
- 用户要求加入版式库时，先备份并使用 revision 检查，只新增或更新授权条目。添加模板不代表清库，更新发行示例不覆盖正在使用的共享库，空库不自动恢复初始模板。

## 仅在用户要求时实际试跑

- 按环境适配读取指定服务、队列与已有 MOSS 工作流，将真实节点的文本与尺寸输出接入采样链。沿用用户模型、编码器、VAE 和采样分支；本次必要的提示词／LoRA 差异需记录，不改保存的原工作流。
- 正常排队，不取消其他任务；保存 prompt ID、请求与 history。中断后先查已保存的 ID，避免重复提交。
- 默认只跑请求的一张。执行失败可定位修复；技术成功而画面不准时，展示真实结果与差异，不自行无上限重跑。

## 验收交付

分别报告格式校验、几何核对、实际采样和看图结果；JSON 编译成功不等于人体、气泡或边界还原正确。按核心规则核对成图，再交付版式、内容、工作流与图片中本次实际生成的文件，并给出可访问链接。未完成的阶段写明限制，不虚构工具执行或视觉验收。
