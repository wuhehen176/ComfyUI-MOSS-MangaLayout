# 已验证示例及局限

以下为案例制作时单次运行的观察，不是其他电脑或 agent 的兼容性、速度或稳定性保证。新任务不必照搬角色、语言、尺寸或步数。

## 阿罗娜：三行背景与整页前景

用 assets/arona/layout.json 与 prompt.json。上方浪纹、中左街景、中右店铺、下方浪纹共四格；大人物归第一格，S 超出 F 覆盖整页，不新增第五格。18 处用途，中文旁白和日文拟声。

初次按截图写黑白，模型仍给主角局部上色。用户要求背景彩色后，同步修改局部颜色、palette、用途及 negative，以同 seed 重跑。

彩色实测：1664×2496，8 步分支，seed 2026102302。四背景和跨格人物保留，路人、店主及背景着色；屈膝姿态未精确复现，左侧小人物还被模型画成全身，未严格服从半身裁切。

教训：截图媒介不自动等于成图媒介，全局声明必须与局部和负面词相容。

## 飞鸟马时：左侧递进与右侧披风

用 assets/toki/layout.json 与 prompt.json。上方脸部、手部扣饰、雪景画外回应、左下表情四格；整页右侧披风人物归第三格，S 扩展到全页右侧。16 处用途，四句连续中文对白。

人物保留金发蓝眼和光环，以参考图毛边兜帽披风作为冬日外搭。实测：1664×2496，8 步分支，seed 2026102303；跨格身体连续，台词完整，最后有轻微微笑。

差异：左下格被扩宽至人物身后，披风变短，主体更正面。应向用户说明，不能宣称严格还原。

此 skill 仅携带几何与普通场景内容 JSON，不携带原漫画图片、服务设置、凭证或原测试环境的工作流。应按使用者的工作流重新连接和验证。
